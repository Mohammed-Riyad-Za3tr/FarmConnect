# FarmConnect Project Report

Date: 2026-03-27

## 1. Project Summary
FarmConnect is a full-stack AgriTech marketplace platform that connects agricultural producers directly with buyers. The system supports a bilingual UI (English/Arabic), role-based access control, product discovery and management, checkout and payment flows, delivery tracking, notifications, and admin verification workflows.

The project is implemented as a monorepo with:
- Web frontend (`apps/web`) built with React + TypeScript + Vite + Tailwind.
- API backend (`apps/api`) built with Express + TypeScript + Prisma + PostgreSQL.
- AI microservice (`apps/ai-service`) built with Python + FastAPI (currently health/service scaffold).
- Shared workspace packages for types, schemas, constants, configs, and UI primitives.

## 2. Technology Stack
- Frontend: React 19, React Router 7, TanStack Query, i18next, Tailwind CSS, lucide-react.
- Backend: Express 5, Prisma ORM, PostgreSQL, Zod, JWT, bcrypt, Helmet, CORS, rate limiting.
- AI Service: FastAPI (Python), Pydantic settings pattern.
- Monorepo Tooling: pnpm workspaces, Turborepo.
- Testing: Vitest (API tests active, web test harness configured).
- Build/Runtime: TypeScript, Vite, tsx watch.

## 7. Database Schema (Prisma/PostgreSQL)

### 7.1 Core Enums
- Roles/identity: `Role`, `UserStatus`, `VerificationStatus`.
- Commerce: `ProductStatus`, `OrderStatus`, `PaymentStatus`, `DeliveryStatus`.
- Payments/finance: `PaymentMethod`, `PaymentEventType`, `PayoutStatus`.
- Notifications/audit: `NotificationType`, `NotificationChannel`, `AuditAction`.

### 7.2 Main Models
- `User`: central identity, role, status, avatar, relations.
- `RefreshToken`: refresh token storage and revocation metadata.
- `ProducerProfile`, `BuyerProfile`: role-specific profile details.
- `ProducerVerificationRequest`: document-based producer verification flow.
- `Address`: buyer saved addresses and order address relation.
- `Category`: hierarchical product categories with localized names.
- `Product`: producer-owned product record with localization fields.
- `ProductImage`: ordered image list per product.
- `Cart`, `CartItem`: buyer cart and line items.
- `Order`, `OrderItem`: immutable purchase records with product snapshots.
- `Payment`, `PaymentEvent`: payment state and gateway event audit trail.
- `Payout`: producer payout tracking.
- `DeliveryTracking`: delivery timeline updates.
- `Notification`: in-app/email/SMS/push event records.
- `AnalyticsDaily`: daily metrics aggregation.
- `AiRecommendation`, `AiForecast`: AI recommendation/forecast entities.
- `AuditLog`: actor-target action history with JSON diffs.

### 7.3 Key Relationship Notes
- One user can have one buyer profile or one producer profile.
- One buyer has one cart; cart has many cart items.
- Orders belong to buyers and contain immutable item snapshots.
- Each order has at most one payment record; payment has many events.
- Products belong to producer profiles; product images are one-to-many.
- Notifications are per user and indexed by read/time dimensions.
